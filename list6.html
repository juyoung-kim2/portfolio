[프로젝트 개요]

  • 커스텀 케이크 주문 서비스를 주제로 한 UX/UI 디자인 및 구현 프로젝트입니다.
    사용자가 옵션 선택부터 주문 완료까지의 과정을 직관적으로 이해할 수 있도록 전체 흐름을 단순화하였으며, 모바일·PC 환경 모두에서 동일한 경험을 제공할 수 있도록 화면 구조와 인터랙션을 구현했습니다. 특히 복잡한 옵션 선택 과정에서의 피로도를 최소화해 사용자 중심의 편리한 주문 경험을 목표로 하였습니다.

[디자인 포인트]

  • 모바일 중심 UX를 기준으로 PC 환경에서도 동일한 흐름을 유지하도록 반응형 구조 설계
  • 단계별 과정이 명확하게 보이도록 시각적 구분(아코디언·분리 영역) 적용
  • 사용자가 선택 상태를 즉시 인지할 수 있도록 시각적 피드백 강화

[배운 것]

  • 마크업 중심에서 벗어나 컴포넌트 구조와 상태 관리를 직접 설계하며 프론트엔드 감각을 확장하고, 디자이너로서 개발 구조를 이해하는 역량을 쌓았습니다.
