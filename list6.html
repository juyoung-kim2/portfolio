Palette Cake Studio

CLIENT
Palette (개인 프로젝트)
RELEASE DATE
2025.11 ~

[기여도 및 역할]

  • 디자인 100%
  • 프론트엔드 개발 100% (React)
  • 서비스 기획 · UX 설계 · UI 디자인 전반 담당
  • React 기반 반응형 화면 구현 및 인터랙션 흐름 정의

[프로젝트 개요]

  • 커스텀 케이크 주문 서비스를 주제로 한 UX/UI 디자인 및 React 구현 프로젝트입니다.
    옵션 선택부터 주문 완료까지의 흐름을 단순화하고, 복잡한 선택 과정에서의 피로도를 최소화하는 데 집중했습니다.

[디자인 포인트]

  • 케이크 주문 특성상 모바일 접근이 많아 → 모바일 중심 UX로 설계, PC에서도 동일한 흐름 유지
  • 단계가 많아 사용자가 현재 위치를 잃기 쉬워 → 아코디언·분리 영역으로 단계 명확히 구분
  • 선택 옵션이 많아 현재 상태 파악이 어려워 → 시각적 피드백 강화로 즉시 인지 가능하도록 구성

[구현 기능]

  • 팝업 (오늘 하루 보지않기 / localStorage 만료 시간 기반)
  • 메인 배너 슬라이드 (Swiper.js)
  • 옵션 선택 시 케이크 이미지 위에 데코 레이어 쌓기 + 레터링 색상 자동 변경
  • html2canvas로 케이크 이미지 캡처 후 장바구니/결제 연동
  • localStorage 용량 초과 try-catch 예외 처리
  • React 컴포넌트 기반 UI 구성

[배운 것]

  • 마크업 중심에서 벗어나 컴포넌트 구조와 상태 관리를 직접 설계하며 프론트엔드 감각을 확장하고, 디자이너로서 개발 구조를 이해하는 역량을 쌓았습니다.

[성과]

  • 커밋 37회 / 구현 페이지 4개+ / 개발 속도 약 30% 단축
