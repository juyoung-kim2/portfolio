[프로젝트 개요]

  • 커스터마이징 케이크 주문 서비스를 주제로 한 UX/UI 디자인 프로젝트입니다.
    사용자가 옵션 선택 → 주문 → 결제 → 완료까지의 과정을 직관적으로 이해하고,
    복잡한 선택 과정에서도 흐름이 끊기지 않도록 실제 서비스 사용 흐름을 기준으로 화면 구조와 인터랙션을 설계했습니다.
    특히 옵션 선택에 따른 상태 변화와 정보 노출 방식에 집중하여, 사용자의 인지 부담을 최소화하는 것을 목표로 기획·디자인하였습니다.

[디자인 포인트]

  • 모바일 중심 UX를 기준으로 설계하되, PC 환경에서는 고정 영역을 활용해 정보 가독성 보완
  • 단계별 정보 노출(아코디언·분리 영역)을 통해 입력 부담 최소화
  • 사용자가 현재 선택 상태를 즉시 인지할 수 있도록 시각적 피드백 강화
  • 단계별 정보 노출(아코디언·분리 영역)을 통해 입력 부담 최소화

[성과 및 기대효과]

  • 복잡한 커스터마이징 주문 과정을 직관적으로 이해할 수 있는 사용자 흐름 구축
  • 선택·입력 과정에서의 피로도를 줄여 주문 이탈 가능성 감소

  • 사용자 행동과 상태 변화를 고려한 인터랙션 설계 역량을 포트폴리오로 명확히 전달
