개인 포트폴리오 사이트

[기여도 및 역할]

  • 디자인 100%
  • 퍼블리싱 100% (HTML5, CSS3, JavaScript)
  • 담당 범위: 메인 UI 디자인 및 퍼블리싱 전 과정 주도

[프로젝트 개요]

  • 취업 준비 과정에서 직접 기획·디자인·퍼블리싱까지 전 과정을 수행한 개인 포트폴리오 사이트입니다.
    단순한 작업물 나열이 아닌, 사용자 경험과 웹 접근성을 고려한 구현에 집중했습니다.

[디자인 포인트]

  • 작업물이 많아도 시선이 분산되지 않도록 → 박스형 레이아웃으로 콘텐츠를 정돈되게 구조화
  • 사용자 환경에 따라 가독성이 달라질 수 있어 → 라이트/다크 모드 모두 자연스러운 색상 변화 구현
  • 감성적인 분위기와 가독성을 함께 잡기 위해 → Pretendard + Playfair Display 조합 적용

[구현 기능]

  • 스크롤 감지 텍스트 등장 애니메이션 (IntersectionObserver)
  • 타이틀 단어 자동 전환 애니메이션 (requestAnimationFrame + setInterval)
  • 경력 더보기 클릭 시 목록 펼치기
  • 헤더 클릭 시 해당 섹션으로 스무스 이동
  • 스크롤 방향 감지 하단 바 고정/숨김
  • 공통 헤더 fetch로 동적 로드
  • 사이드 메뉴 포커스 트랩
  • 다크모드 지원
  • 상단 TOP 버튼
  • PC / 모바일 별도 퍼블리싱

[성과]

  • 키보드만으로 전체 사이트 탐색 가능한 접근성 구현
  • 다크모드 · 반응형 · 접근성까지 직접 설계 및 구현
