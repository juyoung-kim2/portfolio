[프로젝트 개요]

  • 페인트 부자재 판매업체 페인트샵 쇼핑몰 리뉴얼 프로젝트입니다.
    사용자 관점에서 탐색 흐름을 재정리하고, 주요 상품군이 한눈에 보이도록 레이아웃을 단순화했습니다.
    브랜드 메인 컬러와 시각 요소를 활용해 전문성과 신뢰감을 강화했습니다.

[디자인 포인트]

  • 브랜드 메인 컬러(초록)를 활용해 전문성과 신뢰감을 강조한 UI 구성
  • Sans-serif 폰트를 사용해 가독성과 현대적인 분위기 강화
  • 상품군이 직관적으로 드러나도록 레이아웃을 단순화하고 정보 구조 재정리

[성과 및 기대효과]

  • 상품군 중심의 구조 개선을 통해 사용자 탐색 흐름 단순화
  • 직관적인 UI 구성으로 사용성 및 정보 전달력 향상에 기여
  • 효율적인 레이아웃 구성으로 자연스러운 상품 탐색 흐름 형성
