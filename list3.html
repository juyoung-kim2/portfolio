파이드 쇼핑몰 리뉴얼

CLIENT
(주)파이드
RELEASE DATE
2025.10

[기여도 및 역할]

  • 디자인 100%
  • 퍼블리싱 100% (HTML5, CSS3, JavaScript, 카페24)
  • 담당 범위: 메인 UI 디자인 및 퍼블리싱 전 과정 주도

[프로젝트 개요]

  • 피트니스 경기복 브랜드 파이드 쇼핑몰 리뉴얼 프로젝트입니다.
    이미지 중심 와이드 레이아웃으로 브랜드 에너지를 강조하고, 남성·여성 제품군을 명확히 구분해 시각 흐름을 개선했습니다.

[UX 고려사항]

  • 구매 의도가 높아 제품을 자세히 봐야 함 → 착용 이미지 중심 와이드 레이아웃으로 전달력 극대화
  • 여성 신제품 출시로 남·여 제품군 구분 필요 → 배경색 차이로 영역 자연스럽게 구분
  • 스크롤 중 현재 카테고리 파악 어려움 → 스크롤 위치 기반 메뉴 활성화

[디자인 포인트]

  • 착용 이미지가 가장 큰 설득 요소라 → 이미지 중심의 와이드 레이아웃으로 브랜드 에너지 강조
  • 이미지 임팩트가 텍스트에 방해받지 않도록 → 간결한 정보 구조 적용

[구현 기능]

  • 상단 카테고리 클릭 시 섹션 전환 (클래스 토글)
  • 스크롤 위치 기반 메뉴 활성화 (getBoundingClientRect)
  • 카테고리별 중앙 텍스트 스크롤 고정 (fixed → absolute 전환)
  • DISCOVER 버튼 클릭 시 활성 섹션으로 이동
  • 장바구니 카운트 동적 감지 (setInterval)
  • PC / 모바일 별도 퍼블리싱

[성과 및 기대효과]

  • 브랜드 감성을 살린 이미지 중심 UI로 상품 전달력 강화
