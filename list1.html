아모스아인스 쇼핑몰 리뉴얼

CLIENT
(주)아모스아인스가구
RELEASE DATE
2025.04

[기여도 및 역할]

  • 디자인 100%
  • 퍼블리싱 100% (HTML5, CSS3, JavaScript, 카페24)
  • 담당 범위: 메인 UI 디자인 및 퍼블리싱 전 과정 주도

[프로젝트 개요]

  • 사무용 가구 브랜드 아모스아인스 쇼핑몰 리뉴얼 프로젝트입니다.
    제품 이미지가 돋보이도록 미니멀 UI를 구성하고, 타이포 대비와 인터랙션으로 탐색 흐름을 개선했습니다.

[디자인 포인트]

  • 다양한 제품이 시선을 분산시키지 않도록 → 미니멀 UI 구성
  • 사무용 가구 브랜드 특성에 맞게 → 라인·타이포 대비로 깔끔하고 트렌디한 이미지 표현
  • 제품 목록이 많아 정보 과노출 문제를 해결하기 위해 → hover 인터랙션으로 필요할 때만 정보 표시

[구현 기능]

  • 텍스트 마퀴(Marquee) 효과
  • 배너 및 상품 슬라이드 (Swiper.js / linear 무한 자동 슬라이드)
  • 이미지 핫스팟 클릭 시 연동 상품 탭 전환 (jQuery 클래스 제어)
  • 버튼 클릭 shake 애니메이션 (setTimeout)
  • 슬라이드 높이 이미지 기준 동적 계산 (window resize 대응)
  • 마우스 호버 인터랙션
  • PC / 모바일 별도 퍼블리싱

[성과 및 기대효과]

  • 브랜드 톤앤매너를 반영한 UI 개선으로 사용자 경험 일관성 강화
