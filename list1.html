[본인 역할]

  • 담당 범위: 메인 UI 디자인 및 전 페이지 퍼블리싱

[프로젝트 개요]

  • 사무용 가구 브랜드 아모스아인스 쇼핑몰 리뉴얼 프로젝트입니다.
    제품 이미지가 돋보이도록 미니멀한 UI를 구성하고, 타이포 대비와 인터랙션을 활용해 정보 전달과 탐색 흐름을 개선했습니다. 불필요한 요소를 최소화하여 사용자가 제품에 집중할 수 있도록 설계했습니다.

[디자인 포인트]

  • 다양한 제품 이미지가 돋보이도록 미니멀 UI 구성
  • 라인·타이포 대비를 활용해 고급스럽고 트렌디한 브랜드 이미지 표현
  • hover 인터랙션을 적용해 제품 이미지 노출 방식을 개선하고, 사용자가 직관적으로 정보를 탐색할 수 있도록 구성

[성과 및 기대효과]

  • 브랜드 톤앤매너를 반영한 UI 개선으로 사용자 경험 일관성 강화
  • 짧은 일정 내 안정적인 구축 및 오픈 완료
